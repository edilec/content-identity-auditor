# Support

## Public project support

Use the repository issue forms for reproducible bugs and focused feature
proposals. Include the exact version or commit, Node.js version, operating
system, a minimal synthetic reproduction, expected behavior, and observed
behavior.

Remove production content, private URLs, credentials, and personal or customer
data before sharing a reproduction. Issues that require access to a private
catalog or deployment may be closed when they cannot be reproduced safely.

## Support boundary

This project does not include a response-time guarantee, custom editorial
strategy, search-ranking advice, production operations, or private catalog
debugging. It audits the documented identity and cadence invariants only.

For suspected vulnerabilities, follow [SECURITY.md](./SECURITY.md) instead of
opening a public issue. For company enquiries unrelated to this open-source
tool, use [edilec.com/contact](https://edilec.com/contact/).
